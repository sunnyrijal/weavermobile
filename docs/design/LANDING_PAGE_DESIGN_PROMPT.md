# Landing Page Design Prompt for NetworkNest

## Project Overview

**NetworkNest** is an AI-powered relationship management platform that transforms static contacts into a dynamic, explorable, and searchable network. The landing page should communicate the platform's ability to help users manage their personal and professional relationships intelligently through AI-driven features.

---

## Core Value Proposition

**Main Tagline**: "Transform your contacts into a living, breathing network of relationships."

**Key Messages**:
- Turn static contact lists into dynamic, interconnected networks
- Use AI to automatically extract and organize relationship information
- Visualize your entire network in an interactive relationship map
- Ask natural language questions about your contacts
- Never lose track of important relationships and memories

---

## Target Audience

**Primary Users**:
- Professionals managing extensive contact networks
- People who want to maintain meaningful relationships
- Users who struggle with scattered contact information across platforms
- Individuals who want AI-powered assistance in relationship management
- Users who value privacy and data control

**Pain Points to Address**:
- Contacts scattered across multiple platforms (Google, LinkedIn, phone, etc.)
- Difficulty remembering relationship details and context
- Lack of visual understanding of network connections
- Time-consuming manual contact entry and organization
- Forgetting important details about people in their network

---

## Design System & Style Guidelines

### Color Palette
- **Primary Color**: Deep Teal (#008080 / HSL: 180 100% 25%)
  - Use for: Headers, primary buttons, key highlights, navigation
  - Conveys: Professionalism, trustworthiness, stability

- **Secondary Color**: Light Gray (#F0F0F0 / HSL: 0 0% 94%)
  - Use for: Backgrounds, neutral elements, card backgrounds
  - Conveys: Cleanliness, simplicity, spaciousness

- **Accent Color**: Soft Coral (#FF7F50 / HSL: 16 100% 66%)
  - Use for: CTAs, interactive elements, highlights, hover states
  - Conveys: Energy, warmth, action, friendliness

- **Text Colors**:
  - Primary text: Dark Gray (#333333 / HSL: 0 0% 20%)
  - Secondary text: Medium Gray (#666666 / HSL: 0 0% 40%)
  - Muted text: Light Gray (#999999 / HSL: 0 0% 60%)

### Typography
- **Font Family**: Clean, modern sans-serif (e.g., Inter, System UI, -apple-system)
- **Headings**: Bold, clear hierarchy (H1: 3-4rem, H2: 2-2.5rem, H3: 1.5-2rem)
- **Body Text**: 16-18px base size, 1.5-1.6 line height for readability
- **Style**: Contemporary, professional, highly readable

### Visual Style
- **Icons**: Simple, outline-style icons (Lucide icon library style)
- **Aesthetic**: Minimalist, clean, uncluttered
- **Whitespace**: Generous use of whitespace for breathing room and focus
- **Animations**: Subtle, smooth transitions (200-300ms) for interactions
- **Shadows**: Soft, subtle shadows for depth (avoid heavy drop shadows)
- **Border Radius**: Moderate (0.5rem / 8px) for modern, friendly feel

### Layout Principles
- **Grid System**: Responsive grid layout (12-column preferred)
- **Container Width**: Max-width 1280px (7xl) for content, full-width for hero sections
- **Spacing**: Consistent spacing scale (4px, 8px, 16px, 24px, 32px, 48px, 64px)
- **Mobile-First**: Fully responsive, mobile-optimized experience

## Landing Page Structure & Content

### 1. Hero Section
**Purpose**: Immediate value proposition and primary CTA

**Elements**:
- **Headline**: Large, bold headline (48-64px on desktop)
  - Example: "Your Contacts, Reimagined with AI"
  - Alternative: "Never Lose Track of Your Relationships Again"
  
- **Subheadline**: Supporting text (20-24px)
  - Example: "Transform static contact lists into a dynamic, intelligent network. Ask questions, visualize connections, and let AI help you manage your relationships effortlessly."
  
- **Primary CTA**: Large, prominent button (Soft Coral accent)
  - Text: "Get Started Free" or "Start Building Your Network"
  - Style: Large padding, rounded corners, hover animation
  
- **Secondary CTA**: Less prominent link/button
  - Text: "Watch Demo" or "See How It Works"
  
- **Hero Visual**: 
  - Option A: Animated relationship network visualization (nodes and connections)
  - Option B: Screenshot/mockup of the relationship map interface
  - Option C: Abstract illustration representing network connections
  - Should be visually engaging but not overwhelming

**Layout**: Centered content with visual on right (desktop) or stacked (mobile)

## Call-to-Action Strategy

### Primary CTAs
- **Location**: Hero section, final CTA section
- **Text**: "Get Started Free" or "Start Building Your Network"
- **Style**: Large, Soft Coral (#FF7F50), prominent
- **Action**: Link to signup page

### Secondary CTAs
- **Location**: Throughout page
- **Text**: "Watch Demo", "Learn More", "See Features"
- **Style**: Outlined or text link, Deep Teal
- **Action**: Scroll to relevant section or open modal

### CTA Best Practices
- Maximum 2-3 CTAs visible at once
- Clear, action-oriented language
- Prominent but not overwhelming
- Mobile-friendly touch targets (min 44x44px)

## Interactive Elements & Animations

### Scroll Animations
- **Fade-in on scroll**: Features, testimonials, use cases
- **Stagger animations**: Feature cards appear sequentially
- **Parallax effects**: Subtle parallax on hero visual (optional)

### Hover Effects
- **Buttons**: Scale up slightly (1.05x), color shift, shadow increase
- **Feature Cards**: Lift effect, border highlight, icon animation
- **Links**: Color change to accent, underline animation

### Micro-interactions
- **Loading states**: Smooth transitions
- **Form inputs**: Focus states with accent color ring
- **Icons**: Subtle rotation or scale on hover

**Animation Guidelines**:
- Duration: 200-300ms for most interactions
- Easing: Ease-in-out for smooth feel
- Avoid: Overly complex or distracting animations

## Responsive Design Requirements

### Breakpoints
- **Mobile**: < 640px (single column, stacked content)
- **Tablet**: 640px - 1024px (2-column layouts where appropriate)
- **Desktop**: > 1024px (full 3-column layouts, side-by-side content)

### Mobile Considerations
- **Navigation**: Hamburger menu or bottom navigation
- **Hero**: Stacked layout, full-width image
- **Features**: Single column, larger touch targets
- **CTAs**: Full-width buttons for easy tapping
- **Text**: Slightly larger font sizes for readability

### Tablet Considerations
- **Features**: 2-column grid
- **Hero**: Side-by-side or stacked based on content
- **Navigation**: Horizontal menu or hamburger

---

## Accessibility Requirements

- **Color Contrast**: WCAG AA compliant (4.5:1 for text, 3:1 for UI components)
- **Keyboard Navigation**: All interactive elements accessible via keyboard
- **Screen Readers**: Proper ARIA labels, semantic HTML
- **Focus Indicators**: Clear focus states for all interactive elements
- **Alt Text**: Descriptive alt text for all images
- **Text Size**: Minimum 16px for body text, scalable

---

## Performance Requirements

- **Page Load**: < 3 seconds on 3G connection
- **Images**: Optimized, lazy-loaded, WebP format where possible
- **Animations**: GPU-accelerated, 60fps
- **Code**: Minified, tree-shaken, code-split
- **Fonts**: Preloaded, subset if possible

---

## Content Guidelines

### Tone of Voice
- **Professional yet approachable**: Not too corporate, not too casual
- **Clear and concise**: Avoid jargon, explain benefits simply
- **Benefit-focused**: Emphasize what users gain, not just features
- **Trustworthy**: Build confidence through clarity and transparency

### Writing Style
- **Headlines**: Short, punchy, benefit-focused (6-8 words)
- **Body Text**: Scannable, bullet points where appropriate
- **CTAs**: Action-oriented, clear value proposition
- **Features**: Focus on user benefits, not technical specs

- **Framework**: Next.js 15 (App Router)

- **Meta Tags**: Title, description, Open Graph tags
- **Structured Data**: JSON-LD for organization/product
