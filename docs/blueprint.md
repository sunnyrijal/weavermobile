# **App Name**: NetworkNest

## Core Features:

- Contact Views: Provides toggleable views (list, grid, tree) of contacts for efficient network visualization.
- Relationship Map: Interactive relationship map visualization for viewing relationship between connected users.
- Data Management: Provides CRUD operations for contacts and relation data
- Profile input forms: Simple form to input all kinds of user profile and relation information.
- AI-Powered Tagging: Uses a generative AI tool that suggests tags and/or connections based on profile and other metadata, from different networks or profile input

## Style Guidelines:

- Primary color: Deep teal (#008080) for a professional and trustworthy feel.
- Secondary color: Light gray (#F0F0F0) for backgrounds and neutral elements.
- Accent: Soft coral (#FF7F50) for highlighting interactive elements and calls to action.
- Clean and modern sans-serif fonts to maintain readability and a contemporary look.
- Simple, outline-style icons to maintain a minimalist aesthetic and visual clarity.
- Use of whitespace to create a clean and uncluttered interface, improving usability and focus.
- Subtle animations for transitions and interactions to enhance user experience without being distracting.
